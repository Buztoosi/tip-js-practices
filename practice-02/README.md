## Задание 1. Функции, возвращаемые значения и ссылки

### Таблица экспериментов

| № | Прогноз до запуска | Фактический результат | Причина |
| :--- | :--- | :--- | :--- |
| 1. sum(2,3) и sum('2',3) | 5 и 5 | 5 (number) и "23" (string) | Оператор + со строкой делает конкатенацию |
| 2. square(4) | 16 | undefined | В стрелочной функции с телом в {} пропущен return |
| 3. original и alias | original.published = false | original.published = true, original === alias: true | Обе переменные указывают на один объект |
| 4. Копия массива через spread | items не изменится | items[0].name изменился в обоих | Spread создал новый массив, но объекты внутри — общие ссылки |
| 5. Порядок spread | newBook1.available = true, newBook2.available = false | Совпадает | В newBook2 свойство available: true перезаписывается spread-ом oldBook |
| 6. Параметр по умолчанию | "Без названия" для () и undefined, null для null | Совпадает | Значение по умолчанию применяется только при undefined или пропущенном аргументе |

### Исправление эксперимента 2
**Исходный код:**
const square = (value) => { value * value; };

**Проблема:** стрелочная функция с телом в фигурных скобках не возвращает значение автоматически — требуется явный return.

**Исправленный код:**
const square = (value) => { return value * value; };

**Результат после исправления:** square(4) = 16, тип number.

## Задания 2-4. Модель данных и операции

### Распределение ответственности между файлами
- **data.js** — экспорт demoTasks, variantTasks и variantNumber. Только данные, без логики.
- **task-service.js** — 9 прикладных функций. Не импортирует данные, работает только с переданным массивом.
- **main.js** — демонстрационный сценарий: импорт модулей, последовательность действий, вывод результатов, обработка отказов.

### Контракт функции createTask
- **Вход:** id (положительное безопасное целое), title (строка 1-100 символов после trim), priority (одно из "low"/"medium"/"high", по умолчанию "medium").
- **Выход при успехе:** объект с ok: true и полем task.
- **Выход при ошибке:** объект с ok: false и полем error.
- Уникальность id проверяется в addTask, а не в createTask, так как createTask не имеет доступа к списку.
